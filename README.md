# ScreenLink

Веб-прототип для демонстрации экрана с явным согласием участников и записи на стороне зрителя.

## Локальный запуск
1. Установи Node.js 18 или новее.
2. В папке проекта выполни `npm install`.
3. Запусти `npm start`.
4. Открой `http://localhost:3000`.

Для проверки двух устройств в одной сети используй HTTPS-хостинг или локальную HTTPS-среду: браузеры обычно требуют безопасный контекст для `getDisplayMedia()`.

## Размещение в интернете
Проект рассчитан на Node.js-хостинг, который поддерживает WebSocket (например, Render Web Service):
- Build command: `npm install`
- Start command: `npm start`
- После публикации сервис получит HTTPS-адрес.
- Открой главную страницу, нажми «Создать ссылку» и отправь полученный `/room/код`.

## Ограничения прототипа
- Одновременно поддерживается один ведущий и один зритель в комнате.
- Используется STUN для WebRTC. В некоторых сетях может понадобиться TURN-сервер.
- Запись хранится в памяти вкладки зрителя до скачивания; закрытие вкладки удаляет несохранённую запись.
- Видеопоток не сохраняется сервером.
- Передача экрана начинается только после системного разрешения браузера и отдельного согласия в интерфейсе.
- Запись видима участникам; не используйте приложение для скрытого наблюдения.
